# 医院门诊号源预约与候补系统 —— 依赖清单
#
# 安装：
#   python -m pip install -r requirements.txt
#
# 版本说明：下面四个直接依赖全部**锁死实测版本**，不是随手写的下限。
# 理由有二：
#   1. 答辩机器上的环境要能一键复现。若只写 >=，换台机器装出来的是
#      几年后的新版，一旦行为有变，演示现场出问题根本来不及排查。
#   2. 本项目唯一"不那么标准"的用法是同步路由 + SQLite 写锁，
#      它依赖 Starlette 把同步路由丢进线程池这个行为。这个行为是稳定的，
#      但既然整个并发论证都建立在它上面，就没有必要让版本漂移进来。
#
# 只想跑起来、不追求环境一致的话，把 == 改成 >= 也能正常工作。

# Web 框架。只用到了 FastAPI / Starlette 的一小部分：路由、依赖注入、
# Pydantic 请求体、静态文件挂载、统一异常处理器。没有用它的异步特性
# （路由刻意写成同步 def，原因见 docs/CONCURRENCY.md）。
fastapi==0.162.0

# ASGI 服务器。装的是基础版而非 uvicorn[standard]：
# standard 多带的 watchfiles / httptools / uvloop 分别服务于
# 热重载、高性能解析、高性能事件循环，我们一个都用不上 ——
#   · 演示用 scripts/serve.* 启动，刻意不开 --reload
#     （改文件瞬间服务会重启，演示中途编辑脚本就会掉线）；
#   · uvloop 在 Windows 上装不上，而答辩机器多半是 Windows。
# 少装三个依赖，就少三处"换台机器装不上"的风险。
uvicorn==0.54.0

# 测试框架。59 条用例全部是同步函数，没用 pytest-asyncio
# —— 与路由刻意同步是同一个决定：异步只会把并发藏起来。
pytest==9.1.1

# 并发用例需要它。TestClient 会把请求串行化，测不出真正的并发，
# 所以 tests/conftest.py 起了真 uvicorn 进程，用 httpx 走真实 HTTP 打过去。
httpx==0.28.1
